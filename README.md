# Vencade Studios — Downloads

This public repository contains **only distribution manifests and, eventually, downloadable game installers** for Vencade Studios. Source code remains in private repositories.

**Status: PRE-LAUNCH / NOT YET AVAILABLE TO PLAYERS.** There are currently **no public installer releases**. Do not tell players to install anything until Windows QA and official release approval are complete.

## Catalog

`catalog/catalog.json` is a publicly readable HTTPS manifest for the Vencade Studios Launcher:

- `dojoRaiders.available: false` — download disabled until the separate Windows game client is uploaded, checked and published.
- `elevenCup.available: false` — the game is in development. It must remain unavailable.
- The launcher itself checks public **GitHub Releases** for a newer installer and blocks launch while a mandatory update is pending.

The private build artifacts are in the **private** `Venturinii/vencade-launcher` GitHub Actions runs. These artifacts must be downloaded by an authorized maintainer, virus-scanned, code-signed when ready, and manually uploaded to Releases in this public repository. **No GitHub access token, OAuth secret, backend code, or game database belongs in this public repo.**

## Publishing a game version safely

1. Release the specific Dojo Raiders ZIP in this repository, ensuring it downloads anonymously over HTTPS.
2. Confirm SHA-256 of the downloaded public ZIP matches the checksum generated by the private build workflow.
3. Confirm the launcher download link targets exactly this public repository's release.
4. Change `catalog/catalog.json` to `available: true` only after release, setting `version`, `minLauncherVersion`, `executable`, `sha256`, and public `url` to the **verified** release values. Never use placeholders for a live game.
5. Test installation, login, updates and uninstall on a clean Windows PC before publishing the launcher as generally available.

**Never make the private launcher repository public to distribute downloads.**

## Important limitations

- The Dojo Raiders desktop client still uses the online Dojo Raiders website and Twitch authentication. It is not an offline game.
- Twitch login inside Electron must be tested and may require additional OAuth integration.
- The current Windows builds are unsigned development builds; they may trigger Windows SmartScreen.
- Even after source changes are merged, game installation remains locked until signed/public artifacts and a valid, enabled catalog are published.
